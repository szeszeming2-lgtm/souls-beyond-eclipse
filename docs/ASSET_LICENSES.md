# Asset licenses

Every model, texture, animation, sound, music track, font and icon in Souls Beyond: Eclipse is
logged here with where it came from and its license.

## Rules

1. **Original or properly licensed only.** No ripped, fan-extracted or "found online" assets, ever.
   No assets copied or traced from any existing anime or game.
2. **CC0 or project-owned placeholders** are fine while we build. They must be clearly labelled as
   placeholders in game and in `shared-data/assets.json`.
3. **Every asset gets an entry in `shared-data/assets.json`** before it is used: id, spec, status,
   source, license (and author once it is final). The table below is generated from that file, so
   it is always current.
4. **Two platforms, two sets of terms.** Anything that is only licensed for Roblox (Roblox default
   animations, Roblox built-in fonts, Creator Store items under Roblox terms) cannot ship in the
   PC edition. Those rows say "only valid inside Roblox" and need a replacement before Phase 6.
5. **Music and voice** must be original or licensed for both Roblox and Steam distribution.

## How to add an asset

1. Add or update its entry in `shared-data/assets.json` (status, source, license, author).
2. Run `python3 tools/gen_asset_docs.py` to refresh this table and ASSET_SPECS.md.
3. Run `python3 tools/check_all.py` before committing.
